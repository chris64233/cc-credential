# cc-credential

管理职业资质的签发、状态和核验记录。

## 主要业务规则

- **资质类型**：定义编码、名称、有效期天数和必需考核项目集合（`POST /api/credential-types`）。
- **考核结果**：包含全局唯一的外部结果号、人员、项目、通过与否、完成时间和结果有效截止时间；结果事件只增不改（`POST /api/exam-results`）。
- **签发**（`POST /api/credentials`）：
    - 对每个必需项目取该人员完成时间最新的一条结果，必须已通过且在签发时点未过期；最新结果为失败会覆盖历史通过结果，签发时已过期或缺失结果均拒绝签发。
    - 成功时生成全局唯一凭证号、签发时间，到期时间 = 签发时间 + 类型有效期天数，并将实际采用的证据（项目、结果号、完成时间、有效截止时间）快照随凭证保存。
    - 幂等键唯一：相同幂等键 + 相同请求重放返回原凭证（HTTP 200），相同幂等键 + 不同内容返回 409 冲突。
    - `(人员, 资质类型)` 当前有效指针有唯一约束，并发签发同一人员同一资质类型只会产生一张当前有效凭证；已存在当前有效凭证时重复签发返回 409，撤销或自然到期后才可再次签发。
- **状态事件**（`POST /api/credentials/{no}/events`）：支持暂停（SUSPEND）、恢复（RESUME）、撤销（REVOKE），每次操作记录生效时间和原因，事件只增不改。恢复仅允许暂停状态；撤销为终态；事件生效时间不得早于签发时间或上一事件，也不得晚于凭证自然到期时间。
- **核验**（`GET /api/credentials/{no}/verification?at=<时点>`）：依据签发时间、自然到期时间和状态事件重算指定时点的真实状态（`NOT_YET_VALID` / `ACTIVE` / `SUSPENDED` / `REVOKED` / `EXPIRED`，撤销为终态不受到期影响），并返回签发时的证据摘要，而非当前字段。

## 开发环境

- JDK 21
- Spring Boot 4.1.1
- Maven Wrapper 3.9.9
- H2

## 本地运行

启动服务：

    ./mvnw spring-boot:run

运行测试：

    ./mvnw clean test
