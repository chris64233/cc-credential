# cc-credential

管理职业资质的签发、状态和核验记录。

## 主要业务规则

- **资质类型**：定义必需考核项目列表与有效期天数，类型编码全局唯一。
- **考核结果**：包含唯一外部结果号、人员、项目、通过与否、完成时间和结果有效截止时间；结果事件只增不改。
- **签发**：
  - 对全部必需项目，取该人员完成时间不晚于签发时间的最新结果；最新结果必须为通过且在签发时未过期，失败或过期会覆盖更早的通过结果，不得混用。
  - 成功签发生成全局唯一凭证号、签发时间和到期时间（签发时间 + 有效期天数），并保存实际采用的证据快照。
  - 相同幂等键 + 相同请求内容重放返回原凭证；相同幂等键但内容不同返回 409 冲突。
  - 同一人员同一资质类型至多一张当前有效凭证，由数据库唯一约束 `(person_id, type_code, active_key)` 保证，并发签发只会成功一张。
- **状态事件**：凭证可暂停（SUSPEND）、恢复（RESUME）、永久撤销（REVOKE），事件带生效时间和原因，只增不改。
  - 恢复仅允许暂停状态；撤销为终态，之后禁止任何事件。
  - 事件生效时间不得早于签发时间或上一事件，也不得晚于凭证自然到期时间。
- **核验**：按凭证号 + 核验时点，依据签发时间、自然到期和状态事件时间线重放计算该时点真实状态
  （NOT_ISSUED / VALID / SUSPENDED / REVOKED / EXPIRED），并返回签发时的证据摘要，而非当前字段。
  撤销优先于过期：已撤销凭证在自然到期后仍为 REVOKED。

## API 概览

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/credential-types` | 定义资质类型（必需项目 + 有效期天数） |
| GET | `/api/credential-types/{code}` | 查询资质类型 |
| POST | `/api/exam-results` | 录入考核结果（外部结果号唯一） |
| POST | `/api/credentials` | 签发凭证（幂等键 + 人员 + 类型） |
| POST | `/api/credentials/{credentialNo}/events` | 登记暂停/恢复/撤销事件 |
| GET | `/api/credentials/{credentialNo}/verify?asOf=...` | 按任意历史时点核验状态与证据摘要 |

## 开发环境

- JDK 21
- Spring Boot 4.1.1
- Maven Wrapper 3.9.9
- H2

## 本地运行

启动服务：

    ./mvnw spring-boot:run

运行测试：

    ./mvnw clean test
